# HazardSync
### Pre-Disaster Risk Assessment & Preparedness

HazardSync is a disaster management platform designed to support disaster preparedness through rainfall monitoring, risk assessment, weather information and emergency response support.

## Key Features

- Rainfall monitoring and prediction
- Separate User and Admin dashboards
- Emergency camp and shelter management
- Hospital location identification using OpenStreetMap
- Emergency email notifications
- Weather forecast information
- Interactive Google Maps navigation

## Technologies Used

- Python
- Streamlit
- Pandas
- Scikit-learn
- Folium
- OpenStreetMap
- Matplotlib

## Installation

1. Clone the repository:

   git clone https://github.com/parvathikuniyilkattle/Hazard-Sync.git

2. Navigate into the project folder:

   cd Hazard-Sync

3. Create a virtual environment:

   python -m venv .venv

4. Activate the environment:

   source .venv/bin/activate

5. Install dependencies:

   pip install -r requirements.txt

6. Configure your Streamlit secrets.

7. Run the application:

   streamlit run main.py

## Security

Do not upload passwords, API keys, email credentials or private application records.
